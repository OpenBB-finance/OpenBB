# WFGY LLM/RAG Robustness Test Pack Integration

## Overview
WFGY is an external test pack designed to evaluate the robustness of LLM (Large Language Model) and RAG (Retrieval-Augmented Generation) workflows in OpenBB AI systems.

## How to Use
- Integrate WFGY as a test suite in your OpenBB AI workflow pipeline.
- Run the test pack after major updates to LLM or RAG components.
- Review the results to identify weaknesses and improve workflow reliability.

## Documentation
- WFGY documentation is available at: [WFGY Docs](https://github.com/OpenBB-finance/OpenBB/issues/7369)
- Example usage and integration steps are provided in the docs folder.
