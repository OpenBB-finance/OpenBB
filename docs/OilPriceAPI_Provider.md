# OilPriceAPI Commodity Price Provider Integration

## Overview
This feature adds OilPriceAPI as a provider for commodity price data in OpenBB.

## Solution
- Integrated OilPriceAPI for real-time and historical commodity prices.
- Added new provider module and endpoints for commodity price queries.
- Updated documentation and usage examples.

## How to Use
- Use the new provider in your queries: `provider="oilpriceapi"`
- See the API documentation for available endpoints and parameters.

## Notes
- Ensure API keys and credentials are configured if required.
- For troubleshooting, refer to the provider logs and error messages.
