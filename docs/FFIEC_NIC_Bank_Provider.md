# FFIEC NIC Bank Financial Data Provider Integration

## Overview
This feature adds support for FFIEC NIC as a provider for bank financial data in OpenBB.

## Solution
- Integrated FFIEC NIC API for fetching bank financial data.
- Added new provider module and endpoints for data retrieval.
- Updated documentation and usage examples.

## How to Use
- Use the new provider in your queries: `provider="ffiec_nic"`
- See the API documentation for available endpoints and parameters.

## Notes
- Ensure API keys and credentials are configured if required.
- For troubleshooting, refer to the provider logs and error messages.
